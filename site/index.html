"Silently writes no file." The kit loaded. "Saves the case." It did not. Run /reload-plugins or start a new conversation. Reopening the app restores the old one.

How your AI talks to PowerWorld

You talk to the agent in plain English. The agent reaches Simulator one of two ways.

The default: one live Python session

The agent writes Python with esapp, which drives Simulator through SimAuto. It opens the case, writes changes, solves, and reads every write back, because PowerWorld reports success on writes that did nothing.

Fast, scriptable, runs in parallel. Every demo uses it. Needs the SimAuto add-on, which is licensed separately.

No SimAuto: write a file, read a file

Turn on one setting and Simulator watches a folder. The agent writes a .aux script, it lands in the folder, and Simulator runs it and writes the log and result CSVs back out.

You see every script before it runs and keep one you can re-run. It is slower: a dialog has to stay open, and a script that fails the wrong way re-runs until you delete it.

The agent team

A study is more than one command, so 0.4 splits it into roles. They work on measured numbers, ask before changing anything, never save over your case, and answer with a picture where a picture beats a paragraph.

The web can tell you what a command does. It cannot tell you which commands lie about having done it.

Or run /powerworld-hivemind:kb-page. Not on the plugin? Tell your agent to read skills/knowledge-base-page/SKILL.md. It is one markdown file.

Your copy stays yours. A clone does not sync back, so nothing you write is published unless you open a pull request.
